## 1. 문제 설명

-  삼각형의 맨 위에서 시작하여 아래층으로 내려가면서 숫자를 더한다.

한 칸 아래로 내려갈 때는 현재 위치에서 갈 수 있는 두 칸 중 하나만 선택할 수 있다.

예를 들어 다음과 같은 삼각형이 있다고 하자.

    7
   3 8
  8 1 0
 2 7 4 4

위에서 아래로 이동하며 만들 수 있는 경로 중 합이 가장 큰 값을 구하는 문제이다.

예를 들어

7 → 3 → 8 → 7

의 합은

7 + 3 + 8 + 7 = 25

가 된다.

최종적으로 구해야 하는 것은 맨 위에서 시작하여 맨 아래까지 내려갔을 때 만들 수 있는 최대 합이다.

## 2. 내 접근 방식
- 처음에는 각 위치에 도달할 수 있는 모든 경우의 수를 저장하려고 했다.

예를 들어

    7
   3 8

까지 계산하면

[10, 15]

가 된다.

다음 줄

8 1 0

을 계산하면

10 + 8 = 18
10 + 1 = 11

15 + 1 = 16
15 + 0 = 15

이므로

18, [11,16], 15

처럼 가운데 위치에 도달하는 값들을 묶어서 저장하려고 했다.

즉

[
  [18],
  [11,16],
  [15]
]

와 같은 형태를 생각했다.

이후에도

20, [25,18,23], [15,20,19], 19

처럼 계속 확장하는 방식을 떠올렸다.

gpt의 도움으로 정답을 맞추긴 함 
``` 
import java.util.*;
class Solution {
    public int solution(int[][] triangle) {
        List<List<Integer>> arr = new ArrayList<>();
        int answer = 0;
        
        
        for (int i =0 ; i< triangle.length;i++){
            List<Integer>row = new ArrayList<>();
            for(int j =0 ; j < triangle[i].length;j++){
                if (i-1 <0){
                    row.add(triangle[i][j]);
                }else{
                    if(j==0){
                        int data2 = triangle[i][j] + arr.get(i-1).get(j);
                        row.add(data2);
                    } else if(j==i){
                        int data = triangle[i][j] + arr.get(i-1).get(j-1);
                        row.add(data);
                    }else{
                        int data = triangle[i][j] + arr.get(i-1).get(j-1);
                        int data2 = triangle[i][j] + arr.get(i-1).get(j);
                        if(data > data2){
                            row.add(data);
                        }else{
                            row.add(data2);
                        }
                    }
                }
            }
            arr.add(row);
        }
        List<Integer> lastRow = arr.get(arr.size() - 1);
        for(int a : lastRow){
            if(answer <a){
                answer = a;
            }
        }
        return answer;
    }
}
```

## 3. 틀린 이유
1. 같은 위치에 도달한 모든 값을 저장할 필요가 없다

예를 들어 같은 위치에

[11,16]

이 있다고 하자.

다음에 어떤 숫자 x가 오더라도

11 + x
16 + x

가 된다.

항상

16 + x > 11 + x

가 성립한다.

즉

11

은 이후 계산에서 절대로 필요하지 않다.

결국 같은 위치에 도달한 값이 여러 개라면

가장 큰 값만 남기면 된다.
2. 경우의 수를 모두 저장하면 자료구조가 복잡해진다

처음 생각한 방식은

List<List<List<Integer>>>

처럼 3중 리스트 구조가 필요했다.

하지만 이 방식은

for
 └ for
     └ for

처럼 반복문이 계속 중첩될 가능성이 높다.

문제가 커질수록 성능이 급격하게 나빠진다.

3. DP 문제의 핵심을 놓쳤다

처음에는

모든 경로를 저장해야 한다

고 생각했다.

하지만 실제로는

각 위치까지 도달할 수 있는 최대 합만 저장하면 된다

는 사실을 발견해야 했다.
