## 1. 문제 설명

-  주어진 숫자들을 순서대로 사용하면서 각 숫자 앞에 `+` 또는 `-`를 붙여 계산한다.

최종 계산 결과가 `target`이 되는 경우의 수를 구하는 문제이다.

예시

```text
numbers = [1, 1, 1, 1, 1]
target = 3

가능한 식

+1 +1 +1 +1 -1 = 3
+1 +1 +1 -1 +1 = 3
+1 +1 -1 +1 +1 = 3
+1 -1 +1 +1 +1 = 3
-1 +1 +1 +1 +1 = 3
```
정답 : 5

## 3. 틀린 이유
- 실제로 BFS로도 풀 수 있는 문제이다.

다만 구현이 복잡해지고 저장해야 하는 데이터가 많아진다.
왜 DFS(재귀)가 더 적합한가?

이 문제의 핵심은

각 숫자마다
+
또는
-
를 선택한다.

이다.

즉 숫자 하나당 선택지가 2개 존재한다.

1번째 숫자
├─ +
└─ -

2번째 숫자
├─ +
└─ -

3번째 숫자
├─ +
└─ -

이런 트리 구조가 만들어진다.

따라서

한 선택을 끝까지 진행
→ 마지막 숫자까지 도달
→ 다시 돌아옴
→ 다른 선택 진행

을 반복하는 DFS가 매우 자연스럽다.

4. DFS 그림으로 이해하기

예시

numbers = [1, 1, 1]
target = 1

탐색 과정

0
├─ +1
│  ├─ +1
│  │  ├─ +1 = 3
│  │  └─ -1 = 1 ← 정답
│  │
│  └─ -1
│     ├─ +1 = 1 ← 정답
│     └─ -1 = -1
│
└─ -1
   ├─ +1
   │  ├─ +1 = 1 ← 정답
   │  └─ -1 = -1
   │
   └─ -1
      ├─ +1 = -1
      └─ -1 = -3

마지막 깊이에 도달했을 때

현재 합계 == target

이면 정답 개수를 증가시킨다.

## 4. 올바른 접근 풀이
- DFS(재귀)

현재 위치(index)와 현재 합(sum)을 관리한다.

매 숫자마다

+numbers[index]
-numbers[index]

두 가지 경우를 재귀 호출한다.

마지막 숫자까지 사용했다면

sum == target

인지 확인한다.
```
class Solution {

    int answer = 0;

    public int solution(int[] numbers, int target) {
        dfs(numbers, target, 0, 0);
        return answer;
    }

    public void dfs(int[] numbers, int target, int index, int sum) {

        if (index == numbers.length) {
            if (sum == target) {
                answer++;
            }
            return;
        }

        dfs(numbers, target, index + 1, sum + numbers[index]);
        dfs(numbers, target, index + 1, sum - numbers[index]);
    }
}
```

## 5. 배운점
1) DFS는 "선택지를 끝까지 진행하는 문제"에 자주 사용된다.

예시

+ 선택
- 선택

포함
미포함

왼쪽
오른쪽

처럼 선택지가 반복될 때 DFS를 먼저 떠올려보자.

2) 재귀 함수는 현재 상태만 기억하면 된다.

이 문제에서 필요한 상태는

현재 몇 번째 숫자인가?
현재까지의 합은 얼마인가?

뿐이다.

따라서

dfs(index, sum)

형태로 해결할 수 있다.

3) 모든 경우의 수를 저장할 필요가 없다.

처음에는 ArrayList에 모든 결과를 저장하려고 생각했다.

하지만 DFS는

현재 경로만 기억
→ 마지막까지 탐색
→ 되돌아오기

를 반복하므로 별도의 저장 공간이 거의 필요 없다.

기억할 한 줄

"선택지가 2개 이상이고 모든 경우를 확인해야 한다면 DFS(재귀)를 먼저 떠올려보자."
