## 1. 문제 설명

컴퓨터들이 서로 연결되어 있는 정보가 2차원 배열로 주어진다.

```text
1 : 연결되어 있음
0 : 연결되어 있지 않음
```

예를 들어

```text
[
 [1,1,0],
 [1,1,0],
 [0,0,1]
]
```

이라면

```text
0번 컴퓨터 ↔ 1번 컴퓨터
2번 컴퓨터
```

로 연결되어 있다.

즉

```text
(0,1)
(2)
```

총 2개의 네트워크가 존재한다.

문제는

```text
서로 연결된 컴퓨터 집합(네트워크)이 몇 개인지
```

구하는 것이다.

## 3. 틀린 이유
- 이 문제의 핵심은

```text
연결된 컴퓨터들을 하나의 그룹으로 묶는 것
```

이다.

예를 들어

```text
[
 [1,1,0],
 [1,1,1],
 [0,1,1]
]
```

이라면

```text
0 ↔ 1 ↔ 2
```

이다.

0과 2가 직접 연결되어 있지 않더라도

```text
0 → 1 → 2
```

로 갈 수 있다.

따라서

```text
0,1,2
```

는 모두 같은 네트워크이다.

## 4. DFS 그림으로 이해하기

예시

```text
[
 [1,1,0],
 [1,1,1],
 [0,1,1]
]
```

그래프로 표현하면

```text
0 --- 1 --- 2
```

이다.

0번부터 탐색 시작

```text
0 방문
↓
1 방문
↓
2 방문
```

모두 방문된다.

즉

```text
네트워크 개수 = 1
```

이다.

---

다른 예시

```text
[
 [1,1,0],
 [1,1,0],
 [0,0,1]
]
```

그래프

```text
0 --- 1

2
```

탐색

```text
0 방문
↓
1 방문
```

첫 번째 네트워크 발견

이후

```text
2 방문
```

두 번째 네트워크 발견

따라서

```text
정답 = 2
```

## 4. 올바른 접근 풀이
방문 배열을 만든다.

```java
boolean[] visited
```

컴퓨터를 처음부터 끝까지 확인한다.

```text
아직 방문하지 않은 컴퓨터 발견
↓
새 네트워크 시작
↓
DFS 수행
↓
연결된 컴퓨터 전부 방문 처리
↓
네트워크 수 +1
```
```java
class Solution {

    boolean[] visited;

    public int solution(int n, int[][] computers) {

        visited = new boolean[n];

        int answer = 0;

        for(int i = 0; i < n; i++) {

            if(!visited[i]) {
                dfs(i, computers);
                answer++;
            }
        }

        return answer;
    }

    public void dfs(int computer, int[][] computers) {

        visited[computer] = true;

        for(int next = 0; next < computers.length; next++) {

            if(computers[computer][next] == 1
                && !visited[next]) {

                dfs(next, computers);
            }
        }
    }
}
```
예시

```text
[
 [1,1,0],
 [1,1,0],
 [0,0,1]
]
```

초기

```text
visited = [false, false, false]
```

---

### i = 0

방문 안 함

```text
네트워크 개수 = 1
```

DFS 시작

```text
0 방문
↓
1 방문
```

결과

```text
visited = [true, true, false]
```

---

### i = 1

이미 방문

```text
건너뜀
```

---

### i = 2

방문 안 함

```text
네트워크 개수 = 2
```

DFS 시작

```text
2 방문
```

결과

```text
visited = [true, true, true]
```

---

반복 종료

```text
정답 = 2
```

## 5. 배운점
### 1) 네트워크 = 연결 요소(Connected Component)

이 문제는 사실

```text
연결된 그룹이 몇 개 있는가?
```

를 묻는 문제이다.

그래프 문제에서 매우 자주 등장하는 유형이다.

---

### 2) 방문 배열은 필수

방문 체크를 하지 않으면

```text
0 → 1 → 0 → 1 → 0 → 1 ...
```

무한히 탐색할 수 있다.

그래서

```java
visited[node] = true;
```

를 먼저 수행해야 한다.

---

### 3) DFS와 BFS 둘 다 가능

DFS

```text
한 방향으로 끝까지 탐색
```

BFS

```text
가까운 노드부터 탐색
```

둘 다 연결된 컴퓨터를 모두 찾을 수 있다.

이 문제는 DFS가 구현이 가장 간단하다.

---

### 4) 2차원 배열은 그래프의 인접 행렬 표현

```java
computers[a][b]
```

의 의미는

```text
a번 컴퓨터와 b번 컴퓨터가 연결되어 있는가?
```

이다.

```text
1 = 연결
0 = 미연결
```
